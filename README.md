# ConnectHub — Social Media Application

ConnectHub is a full-stack social media web application where users can connect, share posts, and interact with other users.

## Features

- User registration and login with JWT authentication
- User profiles and user search
- Follow and unfollow users
- Create and share posts
- Like and unlike posts
- Comment on posts
- Notifications for likes, comments, and new followers
- Unread notification count and notification management

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT)

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/janhavi5906-gif/ConnectHub.git
   ```
2. Open the project folder:
   ```bash
   cd ConnectHub
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the project root and configure the environment variables required by the application. Never commit this file or share its secrets publicly.
5. Start the server using the start command defined in `package.json`.
6. Open `http://localhost:5001` in your browser.

## Project Purpose

This project demonstrates full-stack web development, REST API integration, database operations, authentication, and interactive social features.
